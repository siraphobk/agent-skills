# Worked examples

Real output from the skills in this repo, kept because a description of what a
skill produces is never as clear as one of its actual files.

All three cover the same job — building this repo and moving off stow — in the
order the skills run:

| File | Skill | What it is |
| :--- | :--- | :--- |
| [`../design/2026-08-14-agent-skills-repo-design.md`](../design/2026-08-14-agent-skills-repo-design.md) | — | The design the plan was drawn from |
| [`2026-08-14-agent-skills-repo-plan.md`](2026-08-14-agent-skills-repo-plan.md) | `write-plan` | Phases, gates, and acceptance criteria, written before any code |
| [`2026-08-14-agent-skills-repo-deliverable.md`](2026-08-14-agent-skills-repo-deliverable.md) | `execute-plan` | What actually landed, including the deviations |

These are frozen copies. The skills themselves write to `.agents/scratch/`,
which is local-only and not tracked — so a plan you run today stays on your
machine and never turns up in a pull request.
